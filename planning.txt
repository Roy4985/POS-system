Phase 1 : Simple Console app

	1. Scope list (Features I want in this 1st part of the project):
		- Add products (name, barcode, brand, family, category, itemcode, quantity, cost price, selling price, TVA (y/n), location + row + column ( if in warehouse))
		- Remove Product
		- List products
		- Find products (by Itemcode or barcode)
		- Add locations
		- Track total quantity / location
		- Transfer from location to another
		- record history of transfers
	
	2. Entity Design :
		enum LocationType{Warehouse, Store}
		enum MovementType{ Transfer, Adjustment}
		
		class Product {
			Id		: Guid
			name	: string
			barcode	: string
			brand	: string
			family	: string
			category: string
			itemcode: string (Exemple : Item0012)
			costp	: decimal
			sellp	: decimal
			TVA		: bool (y/n)
		
		class Location {
			Id	: Guid
			Name: string
			Type: LocationType
		
		class StockEntry {
			ProductId	: Guid
			LocationId	: Guid
			Quantity	: int
			Row			: int //nullable, (used only if LocationType = Warehouse)
			Column		: int
			
		class StockMovement {
			Id				: Guid
			ProductId		: Guid
			FromLocationId	:Guid //nullable
			ToLocationId	: Guid 
			Type			: MovementType
			Quantity		: int
			Timestamp		: DateTime
			
	3. Operations (methods):
		class InventoryManager:
			// Held Data
			List<Product> products
			List<Location> locations
			Dictionary<(Guid product, Guid location), int> stock
			List<StockMovement> movements (Movement history)
			
			// Methods
			AddProduct(name, barcode, brand, family, category, itemcode, quantity, cost price, selling price, TVA (y/n), location + row + column ( if in warehouse))
			RemoveProduct(itemcode)
			ListProducts() (Lists all products)
			FindProduct(itemcode, optional name) (find a specific product)
			GetStock(itemcode, optional name, LocationId) Find product quantity / location
			FindLocation(itemcode) finds where an item is located and quantities
			AddLocation(Name, Type)
			TransferStock(ProductId, FromId, ToId, quantity)
			TransfHist() (shows stock transfer history, needs to be more detailed in later phases)
